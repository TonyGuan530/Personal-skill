# 无头验证

用户选择无头、桌面锁屏或共享IDE不能被占用时，分开执行文件/规则、实际Canvas绘制和微信CLI编译。无头不意味着省略运行图片或用模拟画法代替实际绘制代码。

- 复用项目已有渲染入口，加载实际PNG/图集/字体/皮肤，选可独立执行的真实场景或控件模块。`@napi-rs/canvas` / 浏览器Canvas均可；需要依赖时先查已有本地运行时，不能把引擎迁移当瘦身前提。
- 在独立进程固定时钟/视觉随机种子，对原始图与候选图使用同一渲染代码、状态、字体、背景、视口、DPR和时间点。完整Scene不能无头实例化时可测真实控件模块，报告该范围，不声称整场游戏运行通过。
- 覆盖有关的主题/奖励/动画阶段和典型视口。图集在真实drawImage调用处检查源裁切不越界、目标几何一致（允许浮点舍入量级误差）、目标物理像素不超出纹理覆盖。比较实际成图；整幅图均方误差会被背景稀释，须结合此前独立frame/alpha指标和代表性画面目验。
- 对模块已有的旋转/领取等处理函数执行真实状态迁移，不能把直接设置引擎状态叫做原生触摸验收。若不测原生点击/帧率/手机内存，标NOT_RUN。
- 设置外部进程看门狗，不依靠可能被同步绘制阻塞的setTimeout；只终止自己创建的QA进程。保留失败输出与截图，诊断测试夹具错误和游戏错误。
- 微信CLI预览可独立提供真实编译包大小；无头Skia/浏览器图片须标明后端，不冒充微信模拟器或手机截图。预览不等于正式发布。

示例：原图/缩图版本使用同一个金丹Modal模块，测试六种奖励×待机/旋转/奖励弹出/结果×手机及平板视口；记录drawImage边界、几何差、像素指标和模块按钮迁移。无需重画一张相似弹窗。
