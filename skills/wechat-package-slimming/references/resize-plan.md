# 缩图计划与判定

以原始纹理坐标填写每个正在使用的frame，以及整个动画/镜头范围内最大的逻辑显示长边。DPR用实际Canvas渲染比例，不把CSS设备值与再次ctx.scale相乘两次。若显示不是contain缩放，先适配脚本的渲染模型。

```json
{
  "images": [{
    "path": "minigame/sample/images/atlas.png",
    "width": 1086,
    "height": 362,
    "dpr": 3,
    "regions": [{"name": "reward", "rect": [878,187,399,357], "logicalSize": 36}]
  }]
}
```

`rect`是原图的x/y/宽/高。脚本要求整图等比例、只缩不放、静态8位PNG，所有frame在界内；目标frame像素必须覆盖最大DPR显示。裁切留白会增加整张纹理需求：1254²图里1042px主体显示70×DPR3，整图至少约253px，不能直接把整图缩成210px。目标尺寸留适量余量，再比较实际显示画面。

脚本在各frame的实际物理显示尺寸比较预乘alpha重采样结果，并在深色、米纸、白色底比较合成像素。alpha RMSE≤1.5、P99≤4、max≤32；RGB RMSE≤2、P99≤6、max≤48（均为8位像素值）。这是保守筛选门槛，不代表所有图都应通过，也不代替可读性和真机目验。原图本来有软阴影/发光时保留，不全局硬化alpha。

任一候选不合格、尺寸覆盖不足、路径/备份冲突时，整批apply不修改源图；质量拒绝会保存报告并返回非零。报告可能包含通过的候选，但不代表已实施。空计划、重复路径、越界frame应拒绝。

工具不会改运行atlas坐标、九宫格、触摸区或导出元数据。使用参考坐标 × 实际纹理尺寸/参考尺寸，保持原来的目标几何；检查主体邻图/滤波边距。不等比例缩放、图集重排、分别裁动画状态图应单独设计。

保留尺寸的编码脚本与缩图脚本使用不同指标：前者alpha必须精确，后者在相同显示尺寸比较alpha误差。压PNG只减少文件体积，尺寸不变时不会等比例减少解码内存；缩图才减少像素数量。
