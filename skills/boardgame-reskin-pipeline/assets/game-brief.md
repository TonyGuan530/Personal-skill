# 游戏初始化合同

- 稳定gameId：由初始化命令填入
- 目标阶段：B0；资料建立不代表功能实现
- 目标平台/真实运行入口：待项目确认
- 首发模式：由初始化命令填入；未来想法另列
- 规则来源/版次/扩展/勘误/本地副本：待规则资料填入
- 已确认换皮与画风/冻结区：复用现有决定
- 规则歧义与产品决定：逐项记录出处、影响和裁定人
- 主工程/规则/会话/输入/资源/公共服务位置：按已有架构定位
- 目标人数/设备/比例/包体与性能预算：以产品范围填写
- 首发承诺/非目标/未来能力：不得把未接能力写成可用
- 本包owner/共享文件owner/独立QA：按实际分工填写

## 下一完整交付

目标玩家流程、允许修改范围、前置契约、占位退出条件、完成证据、未测与阻塞、候选版本。先查已有能力清单，不覆盖别的游戏或重复创建全局服务。
