# 分阶段最低能力

先选首发模式再应用。每行登记owner、适用性、实现状态、候选版本与证据。B0的占位不是空按钮：必须明确不可用原因、返回路径、数据契约及启用门禁。B1允许缺美术和次要表现，不能缺合法行动和正常终局。B2/B3对首发必要功能不接受“TODO/稍后接入”。

|ID / 能力|B0至少预留|B1内部可玩至少实现|B2/B3发布要求|
|---|---|---|---|
|RULE 规则与换皮|版次/扩展/原名映射、歧义表、合法人数|全部必需分支、费用/容量/时序/公开与隐藏信息、同分规则|独立原文/手算边界复核；无未裁定的首发关键规则|
|ENTRY 入口与加载|开发/正式能力门禁；加载/错误/取消状态|准备页、合法人数/模式/变种、返回、冷启动与重入|实际分包/懒加载；连点复用加载；失败可重试/返回；旧缓存不可绕过发布门禁|
|LOOP 核心流程|阶段/动作/终局接口；诊断状态|所有合法可选项可触达，包括AI不常选路径；自然终局→排名/同分→重开|多人数/种子及特殊阶段完整对局；无强制回合数假终局、连点穿透重开|
|HELP 规则帮助|自己的规则入口/词汇表/可重看入口|当前阶段、轮到谁、必需选择、卡/角色的时机/效果/限制可看懂|首玩可学会第一轮，教程可跳过/重看；练习不计正式结果；受邀新人教学不阻塞已开局真人|
|INPUT 输入|选择/确认/取消、无效/忙碌/错误状态|点/拖/滚与真实热区一致；非法原因明确；重复提交受控|窄/短/横屏、桌面默认比例、高DPR与安全区实测；隐藏/被裁切对象无热区|
|FEEDBACK 行为反馈|动作→接收→处理中→结果/失败的事件接口|每个关键动作有可见响应、等待与失败出口|不能只有按钮按压；资源/得分/控制权变化可理解；无结果提前泄露或重复奖励动画|
|TIMELINE 演出与菜单|事件序列、跳过意图、输入门禁|演出不改概率/规则；菜单/看详情/主动跳过语义分开|恢复/掉帧/速度设置仍保留因果和最终动作；长连锁可理解，不用跳过掩盖缺事件|
|AUDIO 声音与振动|音效/音乐/振动独立能力与设置接口|可先使用已标占位的音色或明确禁用；视觉信息完整|项目要求的关键音效真实播放；静音/后台/恢复/叠音/销毁验证；音乐可选，振动支持才开放|
|ART 生产资源|全组件清单、已认可风格、源/运行路径|完整核心场景，临时图明确登记且不挡信息|首发关键图/按钮/棋子/状态无临时开发感；alpha/裁切/尺寸/图集/实际渲染与包体合格|
|SAVE 保存与续局|带版本的快照、保存结果、身份/模式命名空间|若承诺续局则合法动作后保存，失败不报成功/不丢恢复态；坏档可解释|杀进程/旧档/容量/失败/同机换账号/重开旧档；本地限定明确。云跨设备续局仅承诺时必验|
|LIFE 生命周期|enter/suspend/resume/dispose边界|本机后台/菜单暂停规则与AI，恢复不失控；离开清理回调|加载中离开、动画中后台、连续进出无悬挂任务；联机菜单不擅自暂停全桌|
|RESULT 结果与记录|稳定match/completion ID、结束原因、可靠提交接口|正常/中断/放弃分开；局内规则得分准确；练习隔离|一局一结果可重试、失败不清掉唯一恢复依据；无重复记录/奖励；无历史证据不猜normal|
|AI 原生电脑玩家（有AI模式时）|合法动作/只读观察/随机或种子接口|AI能完成全部必需分支，不偷看秘密；没有合法动作有规则处理|多人数/种子自然终局、公平/卡死/长链；难度档只有实际有区别才展示|
|SEAT 玩家与信息|我/他人/当前行动者/原生AI/dummy的数据区分|颜色之外有名字/形状/标记；同机隐藏信息交接屏（适用时）|每视角实际权限：手牌/密标/任务/袋序不泄；只读信息不伪装可点按钮|
|ROOM 在线房间（仅online）|创建/加入/邀请/准备/人数/版本/错误契约|真实权威服务接通、主机离开/满房/重开流程；能力门禁|合法身份/云版本/权限及多客户端实测；不能以单机多座位声称联机|
|SESSION 连接与托管（仅online）|身份/成员/连接/控制分离，等待/失联政策表，木偶状态占位|服务端判断失联、AI托管、同步收回、暂离与正式退席；全员离线策略|AI与收回竞态、旧连接/旧局、全部失联/恢复、计时边界和真实多设备；明确区分nativeAI/dummy|
|WAIT 等待（适用模式）|玩法截止、无交互、决策阻塞、网络超时分别建模|已完成者不催；自己需做什么明确；慢玩家可继续合法操作|快慢混合与锁期间边界验证；不把统一普通倒计时当“久未操作”；额外小游戏仅明确需求时做|
|SYNC 权威与重试（仅online）|match/decision/control/run版本，requestId与未知回执状态|服务器验动作/身份；幂等、乱序/迟回包拒绝、未知结果先核对|条件写/事务真边界、保存后丢ACK、同房换局/同版ABA、所有writer不可绕过；秘密仅按viewer投影|
|PLATFORM 公共服务|能力声明与窄adapter：存储/结果/设置/资源等|本游戏实际接入或诚实降级；业务UI不反向支配公共服务|公共变更覆盖实际消费者；生成云副本、部署版本、动态资源引用可追踪|
|PERF 性能与可用性|平台/设备/包/帧时/内存目标，非口头60fps|完整局无卡死、资源可释放、静止降频适用|实际长局/峰值/多尺寸/目标设备证据；诊断与测试开关关闭，日志不泄私密数据|
|ACCOUNT 身份与进度（有账号时）|可信身份来源与本地/云进度分离|切账号不串数据，迟回包/队列绑定原身份|同机换号；承诺换机则真实跨设备核验；头像/昵称不是身份或权益证明|
|ENT 权益/付费/CDKEY（仅启用时）|调用共享权益边界；禁用购买占位；价格/策略待证|开发模拟明确标注，未授权不交易|平台资格与当前规则、服务端验权/通知幂等/退款来源/本局资格/CDKEY一次性/到账对账；客户端owned不发货|
|REWARD 可兑换奖励（仅启用时）|结果→可信证明→账本→权益分离|开发模拟无真实兑换、重复事件不重复给奖|离线可篡改进度不能直接当可信付费资格；历史来源/额度/补领/退款按已定政策独立验|

没有AI/online/账号/付费的首发可以标N/A并说明范围。基础玩法之外的云功能不强加；但存储按钮、教程入口、音效开关或“多人”宣传已经存在，就必须验真实行为或诚实撤下该承诺。
