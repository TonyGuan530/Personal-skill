# 自检与定点返修

检查强度随修改范围变化；不为一个图标跑整个应用，但不能只看生成器大图就宣布替换完成。

## 第一层：资源

- 文件真实解码，格式、颜色、alpha、尺寸符合用途；透明对象在深/浅底上无污染边、白角、烘焙棋盘格或不合理硬锯齿。
- 实际可见边界与安全区正确；插画主体在真实容器裁切后仍完整；图标缩小后可辨。
- 图集逐项对应逻辑ID，缺件/重复/错位不能用“图集已经生成”忽略。frame以最终运行图为准，压缩、裁切、重排后复查。
- 九宫格/端帽在最窄与最宽用途下无拉扯；运行压缩图与源图分离，不把大源图意外入包。

## 第二层：界面

- 在完整页面看层级、对齐、间距、基线和视觉重量。华丽边框不能抢正文，主题一致不等于每个元素都铺同一纹理。
- 框体可用内容区已按新边框重算。长名称、两位/多位数字、换行、错误文案和字体放大不溢出、不被装饰压住。
- 控件正常、选中/按下、禁用、加载、错误及实际存在的焦点/hover状态可分辨；不要为了凑状态新增功能。
- 高亮沿真实可见轮廓，中心、比例、角度及动画变换一致；禁用遮罩、阴影和波纹不越界污染邻居。
- 测试代表性窄/宽尺寸和安全区，不机械规定所有项目同一套机型。不得靠整体缩小全部文字掩盖布局缺陷。

## 第三层：交互与动画

- 实际触摸/鼠标/键盘路径验证目标动作。检查按钮中心、边缘、邻近控件、透明空白区域及放大后新增可见区域，确认输入边界是有意设计。
- 禁用、隐藏、遮罩、转场和动画中不误触、不穿透、不重复提交；恢复后正常可操作。
- 渐入/渐出无闪现；循环特效与状态一致；切页、重进、后台恢复后无残留。若特效暗示危险强度，使用真实状态和实际阈值，而不是固定猜测值。
- 动画不能提前暴露隐藏结果、改变结算或重复奖励。重绘频率、透明图层和纹理体积与目标设备预算相称。

## 判定与停止

逐项标记 PASS / FAIL / NOT_RUN / BLOCKED，并附版本、尺寸/状态和截图或日志位置。只标有证据的层级，不用漂亮的组件拼图冒充目标设备验证，也不以测试数量计算视觉完成率。

FAIL回到最近原因：

| 症状 | 优先修复 |
| --- | --- |
| 人物/主体被裁掉 | 重新构图或修容器fit策略 |
| 绿/白边与锯齿 | 去污染、alpha/采样/导入处理；先看深浅底 |
| 厚边框挤字 | 调整内容区、布局与字号层级 |
| 特效外形不同 | 共用轮廓/遮罩、坐标和变换 |
| 点击和图形不对应 | 可见边界、热区、事件传播 |
| 默认状态好看，其余像占位 | 补实际存在的状态并跑切换 |
| 看起来像完成但功能不可用 | 接通实际组件，保留失败/恢复路径 |

同一具体问题连续两次无改善时换方法或说明缺必要条件；不要无限调用生成工具。未测设备/平台保留缺口，不把全部检查转给用户。
